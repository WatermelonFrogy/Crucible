Orangenium = 3 Iron + 1 Copper Ore
Cupralite   = 3 Copper + 1 Iron Ore
Ferracite   = 5 Iron + 1 Iron Ore
Bronzium    = 5 Copper + 1 Copper Ore

Embersteel  = Orangenium + Ferracite
Duskbronze  = Bronzium + Cupralite
Frostiron   = Ferracite + Cupralite
Sunsteel    = Orangenium + Cupralite
Storm Alloy = Ferracite + Bronzium
Bloodmetal  = Orangenium + Bronzium

Voidiron     = Embersteel + Frostiron
Starbronze   = Duskbronze + Sunsteel
Deepsteel    = Storm Alloy + Frostiron
Auricite     = Sunsteel + Bloodmetal
Moonsteel    = Frostiron + Duskbronze
Dawn Alloy   = Sunsteel + Embersteel
Night Alloy  = Voidiron + Moonsteel
Tempestium   = Storm Alloy + Starbronze
Glacialite   = Frostiron + Moonsteel
Cinder Alloy = Embersteel + Bloodmetal

Kingsmetal    = Auricite + Dawn Alloy
Witchsteel    = Night Alloy + Cinder Alloy
Dragonsilver  = Tempestium + Auricite
Titanbronze   = Deepsteel + Starbronze
Astralite     = Kingsmetal + Tempestium
Obsidiansteel = Witchsteel + Deepsteel
Runegold      = Kingsmetal + Dragonsilver
Celestium     = Astralite + Runegold
Umbrasteel    = Obsidiansteel + Witchsteel
Crucibrium    = Celestium + Umbrasteel
